# Azalea Initiative

A first website prototype for the Azalea Initiative: a student-led community connecting Bay Area volunteers with people with disabilities and caregivers in Taiwan through art, messages, service, and fundraising.

Read [DESIGN.md](./DESIGN.md) for product goals, safety and consent requirements, fundraising guidance, and the proposed roadmap.

## Run locally

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

The drawing and message interactions are currently frontend-only prototypes. Artwork remains in the browser unless the visitor downloads it. A moderated backend and verified donation provider are required before public launch.
