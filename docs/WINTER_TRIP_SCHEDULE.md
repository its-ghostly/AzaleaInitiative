## 1. Passport & identity

| When | What |
| --- | --- |
| **Immediately** | Confirm every traveler has a **valid U.S. (or other) passport**. Name must match the ticket. |
| **By Nov 8, 2026** | Passport physically in hand. If renewing/first-time, start **now**—routine U.S. passport timing can exceed the weeks left before Dec. |
| **Validity** | Passport should remain valid through **at least Jan 3, 2027** (prefer **6+ months beyond** return date to avoid airline/immigration issues). |
| **Copies** | Clear color scan of photo page to ops (secure storage only—**never** commit to this git repo). Parent keeps a paper copy. |
| **Under-18** | Passport number goes on the notarized consent form. |

**Taiwan entry:** Most U.S. passport holders do **not** need a visa for short tourist/volunteer stays in this length—but **verify current rules** for each nationality before booking. Non-U.S. passports: check visa / entry permit early.
